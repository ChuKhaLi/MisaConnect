# Archived Spec Kit slices

`001`–`009` are the Spec Kit slices behind the .NET work shipped up to MisaConnect 2.4.0. They are kept as a read-only record: the CHANGELOG, docs and code comments link to them.

Spec Kit is no longer used. New work starts from a design in [`docs/superpowers/specs/`](../docs/superpowers/specs/) and a plan in [`docs/superpowers/plans/`](../docs/superpowers/plans/) — see [the constitution](../docs/constitution.md), Principle V.
