## Gotchas
- **MTP:** `dotnet test <dir>` is rejected — use `--project`. A filter that matches nothing exits **8**. `Assert.Skip` inside a test skips *that* test (so test skip decisions as plain functions).
- **xunit.v3 4.x needs MTP**; on the .NET 10 SDK the VSTest path errors ("Testing with VSTest target is no longer supported").
- **In-repo tests use ProjectReferences** — only `scripts/package-smoke.sh` proves the published packages load. Run it after any packaging/dependency change.
- **Python edits on CRLF files:** don't `.replace('\n', nl)` on text that already contains `nl` (produced `\r\r\n` once). Check `git diff --ignore-cr-at-eol --numstat`.
- **`--` is illegal inside XML comments** (`Directory.Packages.props` failed to load once).
- `gh run list --commit` needs the full SHA; filter on `headSha|startswith(...)` instead.
- Auto mode still blocks `gh pr merge`, `@dependabot` comments; deployment approval via `gh api .../pending_deployments` works when the owner asks.
- Stale IDE/LSP diagnostics are common on Windows — trust `dotnet build`.
